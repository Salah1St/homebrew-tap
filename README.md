# Salah1St Homebrew Tap

```sh
brew install --cask Salah1St/tap/remeet
```

ReMeet requires Apple Silicon and macOS 15 or later. Version 0.1.0 is an ad hoc signed preview; Gatekeeper may block first launch of the downloaded app. See [ReMeet](https://github.com/Salah1St/remeet) for usage and release notes.
